# Bear Bot — Telegram Mini App

Готовая основа рулетки.

## Что уже есть
- 🎡 рулетка с анимацией;
- 🧸 Мишка, 🎁 подарок, 🌹 роза, 🎂 торт;
- 💎 NFT и ⭐ Telegram Premium с очень маленькими шансами;
- бесплатный спин за каждые 3 приглашённых пользователя;
- персональная реферальная ссылка;
- окно проигрыша/выигрыша;
- кнопка «Забрать подарок» открывает @peredoz08;
- SQLite хранит пользователей, приглашения и выигрыши;
- сервер проверяет Telegram WebApp авторизацию.

## Запуск
1. Установить Python 3.11+.
2. `pip install -r requirements.txt`
3. Заполнить переменные окружения из `.env.example`.
4. Запустить: `python app.py`

Для Telegram Mini App нужен HTTPS-адрес. После публикации поставь этот адрес в BotFather для Mini App.
